FINAL FIREBASE STEP

1. Open Firebase Console > Firestore Database > Rules.
2. Delete the existing rules shown in the editor.
3. Copy everything from firestore.rules into the editor.
4. Click Publish.

The account and messaging system will remain locked until these rules are published.
Never use test mode rules for the public website.

The system includes:
- Email/password authentication
- Unique public usernames (3-20 characters)
- Passwords of at least 6 characters
- Friend requests
- Private real-time chat between friends
- Blocking and reporting
- Forgot-password emails and password changes
- Unread message counters
- Online and last-active status
- Custom display names, emoji avatars, and bios
- Friend game activity
- Friend profile cards
- Typing indicators and read receipts
- Do Not Disturb and activity privacy
- Public game ratings
- Playtime and achievements
- Cloud-synced appearance settings (very large background images stay on each device)
- Optional message notification sounds
- Removing friends and deleting your own messages
- Username changes with a 30-day cooldown
- Earned profile badges
- Most-played and top-rated sorting
- Game loading timeouts with retry controls

IMPORTANT: Publish the included firestore.rules again for ratings, message deletion,
and username changes to work.

Firebase Authentication stores passwords securely. The website never stores raw passwords.
